TapTheTab

Every window, one tap away.

A fast, keyboard-first window switcher for macOS. Hold ⌥, tap ⇥, see every window. Type to search. Let go to switch.

Download for macOS View on GitHub

Free and open source (MIT) · macOS 13 or later · Developer ID signed and notarized

Windows, not just apps

macOS’s ⌘⇥ switches apps, not windows. With three Safari windows and two editor projects open, getting to the right one means ⌘⇥, then ⌘`, then guessing.

TapTheTab shows every window in one place, ordered by when you last used it, and lets you jump to any of them by typing a few letters of its title. ⌥⇥ sl ⌥ goes to Slack. ⌥⇥ gh pull ⌥ goes to the GitHub pull-request tab, in whichever browser it lives in.

Features

Small and quick, with room to make it yours.

All windows, most recent first

Including minimized windows and hidden apps (each can be filtered out). A quick tap goes back to the previous window without the panel ever flashing.

Type to search

Fuzzy, case- and accent-insensitive, across titles and app names. Matches are highlighted, and what you picked ranks first next time.

Quick select, peek, pin

⌘1–9 jumps straight to a window, ⇧Space peeks at it full size, ⇧P pins an app to the top.

Act without switching

Close, minimize, make fullscreen, hide or quit from the switcher. ⇧D sends a window to your next display.

Liquid Glass

See-through glass on macOS 26 (Clear or Tinted), a similar translucent look on earlier versions, or the classic dark panel.

Themes

Soft gradients with grain: eleven presets or your own colors. The Settings window follows.

Thumbnails and previews

Optional live window thumbnails in the grid and the list, and a large preview of the selected window on its own floating card.

Move it

Drag the list or the large preview anywhere while the switcher is open. It remembers where.

A layout per shortcut

Grid or list, three sizes. For example ⌥⇥ as a grid and ⌥` as a list for the current app.

Several displays

Shows on the display with your mouse, the active window or the main display, and can list that display’s windows first.

Easy to start

A first-run tour walks through the keys, and you can reopen it any time. Any shortcut works, including ⌘⇥.

Your language

English, Italian, Turkish, German, French and Spanish, with VoiceOver support.

Scriptable

tapthetab:// links open the switcher pre-filtered, for launchers, Shortcuts and the terminal.

Hackable

A plain-text JSON config that reloads when you save it, and a pure-Swift core with unit tests that run on any platform.

Screenshots

Drawn by the app itself from made-up windows, in light and dark.

Keys

While you hold the trigger modifier (⌥ by default).

KeysWhat happens
⌥⇥Open the switcher, select the previous window
⇥ / ⇧⇥Next / previous window
← → ↑ ↓Move around the grid
letters, digitsSearch
⌫Delete the last search character
release ⌥Switch to the selection
↩Switch to the selection
⎋Clear the search; press again to close
Space (empty search)Keep the switcher open after you release ⌥
⌘1…9Switch straight to that window (⌃ instead of ⌘ when your shortcut uses ⌘)
⇧SpacePeek: show the selected window full size where it is; again to go back (needs Screen Recording)
⇧WClose the window
⇧MMinimize / restore the window
⇧FToggle fullscreen
⇧HHide / show the app
⇧QQuit the app
⇧XClose all of the app’s windows
⇧DMove the window to the next display
⇧PPin or unpin the app (pinned apps’ windows come first)
⌥`The same, but only the current app’s windows

The mouse works too: hover to select, click to switch, click outside to dismiss. Shortcuts are yours to change in Settings.

Install

Needs macOS 13 or later. The only required permission is Accessibility.

Homebrew

brew tap memoliertorerr/tapthetab https://github.com/memoliertorerr/tapthetab
brew install --cask tapthetab

Update later with brew upgrade.

Disk image

  1. Download TapTheTab-<version>.dmg from the latest release.
  2. Drag TapTheTab into Applications and open it.
  3. Grant Accessibility when asked (System Settings → Privacy & Security → Accessibility).

Releases are signed with a Developer ID and notarized by Apple, and list SHA-256 checksums in SHA256SUMS.txt.

Privacy

No telemetry. No analytics, no accounts, nothing about you or your windows is collected.

  • No network access unless you turn on automatic update checks (off by default). Then, once a day, TapTheTab asks GitHub for the latest release. Nothing about you or your Mac is sent beyond that request.
  • Updates are verified (Developer ID signature and checksum) before installing. Homebrew installs update with brew upgrade.
  • Permissions: Accessibility is required to listen for the shortcut and list windows. Screen Recording is needed only if you turn on live previews, which are kept in memory and never saved.
  • Your settings are one readable JSON file on your Mac, with owner-only permissions. This website has no scripts, no cookies and no third-party requests.
  • Open source: read every line in the repository. To report a vulnerability, see SECURITY.md.
